## Product Purpose

Fagan's Ghost resurrects Michael Fagan's 1976 formal code inspection inside Kiro. AI agents play the fixed roles (Moderator, Reader, Inspectors, Scribe), hooks run the ceremony, and a deterministic MCP server keeps the defect log honest. The Inspection Room is the static viewer that plays back a real exported inspection so the process is legible, dramatic, and auditable. Success: a viewer can follow a real inspection end to end (open, paraphrase, defects, rework, follow-up) without explanation, and a developer can audit every event.

## Positioning

It is not an AI code reviewer. It is a faithful reenactment of a dead, proven process: fixed roles, entry and exit criteria, a defect log with measured rates, and a record that keeps the AI honest. The seance metaphor (inferred binding): the ceremony is acted out by spirits around a table because the method itself is a ghost.

## Operating Context

- Static viewer (Vite + TypeScript, no backend, no model calls) deployed to GitHub Pages.
- Loads only real JSON produced by `fagan-mcp export_report`. Demo data is an actual inspection of this repo's own code.
- Shown in a sub-3-minute demo video and linked from the Devpost submission.

## Capabilities and Constraints

- Replay of exported inspections: role table, Reader paraphrase, defects pinned to code lines, follow-up resolution.
- Required states: reduced motion, keyboard navigation, readable contrast, and a plain report-view toggle.
- Plain files under `.fagan/inspections/<id>/` are the source of truth; the viewer never fabricates events, defects, metrics, or quotes.
- TypeScript strict; Vitest + fast-check property tests; Playwright smoke test.
- Free tier only; no paid APIs; no copyrighted horror assets; no jump scares or gore.
